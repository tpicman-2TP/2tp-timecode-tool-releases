# 2TP Timecode Tool – downloads

Timecode converter, monitor and show cue stack: LTC, MTC and Art-Net in and out, internal generator, offset,
freewheel and frame-rate conversion, web viewer, NDI, OSC and a Bitfocus Companion module. The converter is free –
**Timecode Tool Pro** adds the SHOW cue stack (groups, sub-cues, loops, notes) and REHEARSAL.

**Download:** see [Releases](../../releases/latest) – the newest Windows installer
(`Timecode-Tool-Setup-x.y.z.exe`, Windows 10/11, 64-bit). macOS version: by the end of November 2026.

**Pro licence:** [www.2tpvisuals.com](https://www.2tpvisuals.com/#tools) – the key comes by e-mail; enter it in the
app with **Get Pro** in the header.

The app checks this page once a day for a newer version (only the app version is sent) and shows an **Update**
button when there is one. Nothing is downloaded or installed by itself.

This repository holds only the installers and release notes – no source code.
